# Ghid Auto Plus

Ghid Auto Plus este un proiect pentru proprietarii auto.

## Funcții
- Verificare auto înainte de cumpărare
- Evidența mașinilor
- Calculator de costuri
- Planificarea schimbului de ulei și a reviziilor
- Evidența consumului de combustibil
- Bibliotecă informativă de coduri OBD-II
- Rapoarte și backup de date

## Versiune
MVP 1.0 — versiune de testare.

## Important
Informațiile OBD-II sunt orientative și nu înlocuiesc diagnoza unui mecanic. Funcțiile Premium și plățile reale nu sunt încă activate.
